# Benchmark-informed figure planning checklist

## Internal evidence
- [ ] Methods read
- [ ] Results read
- [ ] source tables inspected
- [ ] frozen authority identified
- [ ] result inventory created
- [ ] re-analysis policy identified

## Benchmarks
- [ ] target journal searched
- [ ] similar scientific question searched
- [ ] similar data modality searched
- [ ] benchmark set relevance documented
- [ ] scientific architecture extracted
- [ ] visual grammar extracted
- [ ] exact layouts/artwork not copied

## Mapping
- [ ] each benchmark pattern classified
- [ ] unavailable evidence marked
- [ ] optional new analyses separated
- [ ] no unavailable panel promoted

## Candidate plans
- [ ] at least one contribution-forward plan considered
- [ ] alternative plans generated only when scientifically plausible
- [ ] each panel has unique evidence role
- [ ] main/Supplementary allocation justified
- [ ] candidate scores completed

## Promotion
- [ ] scientific fidelity PASS
- [ ] claim coverage PASS
- [ ] contribution visible
- [ ] evidence boundary intact
- [ ] journal fit acceptable
- [ ] source traceability complete
- [ ] manual expert review PASS
