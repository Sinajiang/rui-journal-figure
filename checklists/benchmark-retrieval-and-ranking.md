# Benchmark retrieval and ranking checklist

## Search brief
- [ ] target journal identified
- [ ] topic/disease extracted
- [ ] study design extracted
- [ ] modality extracted
- [ ] primary estimand/outcome extracted
- [ ] desired figure roles extracted

## Search
- [ ] target-journal scientific search completed
- [ ] target-journal method search completed
- [ ] peer-journal search completed
- [ ] field-defining fallback used only if needed
- [ ] multiple query families used

## Candidate provenance
- [ ] title verified
- [ ] journal verified
- [ ] year verified
- [ ] DOI/URL recorded
- [ ] article type recorded
- [ ] retrieval date recorded
- [ ] search query/round recorded
- [ ] figure-detail verification status recorded

## Ranking
- [ ] scientific similarity scored
- [ ] method similarity scored
- [ ] modality similarity scored
- [ ] sample structure scored
- [ ] figure-role relevance scored
- [ ] journal fit scored
- [ ] main/supp transferability scored
- [ ] accessibility scored
- [ ] recency scored

## Selection
- [ ] duplicates removed
- [ ] final set relevance adequate
- [ ] journal/design/figure-role diversity adequate
- [ ] no candidate selected solely for prestige
- [ ] benchmark dossier generated

## Saturation
- [ ] search rounds logged
- [ ] minimum count met
- [ ] stopping rule evaluated
