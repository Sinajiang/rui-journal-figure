# Real-data figure production checklist

## Preconditions
- [ ] architecture promoted
- [ ] scientific authority locked
- [ ] source data available
- [ ] rerun policy known
- [ ] target journal known

## Render specification
- [ ] every panel has chart type
- [ ] every quantitative panel has source
- [ ] column mappings explicit
- [ ] filters explicit
- [ ] transformations explicit
- [ ] ordering explicit
- [ ] uncertainty definition explicit
- [ ] semantic colors defined

## Scientific sentinels
- [ ] row/sample counts
- [ ] key effect values
- [ ] P/FDR where applicable
- [ ] critical category/status sets
- [ ] sentinel validation PASS

## Outputs
- [ ] PDF
- [ ] SVG
- [ ] TIFF
- [ ] PNG preview
- [ ] panel source-data TSVs
- [ ] provenance JSON
- [ ] render log

## QA
- [ ] PDF opens correctly
- [ ] actual font size PASS
- [ ] collision audit PASS
- [ ] layout audit PASS
- [ ] journal contract PASS
- [ ] source traceability PASS
- [ ] manual final-size visual review PASS

## Promotion
- [ ] promoted separately from architecture prototype
- [ ] manuscript citations updated
- [ ] legend updated
- [ ] evidence graph re-audited
