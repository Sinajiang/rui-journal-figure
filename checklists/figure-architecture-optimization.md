- [ ] evidence inventory complete
- [ ] evidence graph complete
- [ ] benchmark dossier complete
- [ ] journal contract current
- [ ] panel candidate inventory complete

## Panel candidates
- [ ] availability classified
- [ ] must-main status declared
- [ ] claim IDs mapped
- [ ] source IDs mapped
- [ ] evidence family declared
- [ ] visual density estimated
- [ ] benchmark support recorded

## Optimization
- [ ] redundancy matrix generated
- [ ] 3-figure candidate evaluated if permissible
- [ ] 4-figure candidate evaluated if permissible
- [ ] 5-figure candidate evaluated if permissible
- [ ] weighted claim coverage audited
- [ ] visual density audited
- [ ] main/Supplementary efficiency audited
- [ ] unavailable evidence excluded

## Actions
- [ ] PROMOTE/KEEP decisions justified
- [ ] MERGE decisions justified
- [ ] DEMOTE decisions justified
- [ ] REPAIR candidates identified
- [ ] optional new analyses kept outside promoted plan

## Promotion
- [ ] no hard gate failure
- [ ] benchmark count used only as soft prior
- [ ] scientific contribution visually obvious
- [ ] expert scientific review PASS
