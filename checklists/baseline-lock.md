# Baseline lock checklist

A figure can be baseline-locked only if:

- [ ] figure-level claim is correct
- [ ] anchor panel is visually dominant enough
- [ ] panel order follows the evidence chain
- [ ] no panel is redundant
- [ ] group colors are correct
- [ ] chart types are appropriate
- [ ] data density is adequate
- [ ] no major collision exists
- [ ] the baseline is clearly better than alternatives

After lock, default to surgical repair.
