# Manuscript–figure reintegration checklist

## Claim mapping
- [ ] every main Results figure claim has a stable claim ID
- [ ] claim strength declared
- [ ] evidence status declared
- [ ] each figure/panel citation resolves

## Panel mapping
- [ ] every evidence panel links to source data
- [ ] every quantitative panel declares statistic
- [ ] every non-workflow panel links to at least one claim or is explicitly contextual/boundary

## Legend mapping
- [ ] legend panel set matches promoted panel set
- [ ] legend panel order matches artwork
- [ ] legend no longer describes retired panel architecture

## Supplementary
- [ ] S-figure numbering sequential
- [ ] S-table numbering sequential
- [ ] all cited Supplementary items exist
- [ ] no retired numbering remains

## Claim-strength audit
- [ ] replication claims use direct replication evidence
- [ ] contextual evidence not described as replication
- [ ] association not described as mechanism
- [ ] noncausal findings not described causally

## Final decision
- [ ] automated hard gates PASS
- [ ] manual scientific review PASS
- [ ] exact-version manuscript + figures + legends locked
