# Panel review checklist

For each panel:

- [ ] What unique scientific role does it serve?
- [ ] Is the chart type appropriate?
- [ ] Are individual observations shown when useful?
- [ ] Are uncertainty and sample size represented correctly?
- [ ] Are labels concise?
- [ ] Is any legend avoidable through direct labeling?
- [ ] Does any annotation touch data, lines, borders, or labels?
- [ ] Is the panel too sparse or too dense?
- [ ] Does the panel belong in the main figure?
