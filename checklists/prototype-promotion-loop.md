# Prototype promotion loop checklist

## Prototype
- [ ] marked NO DATA
- [ ] no fabricated values shown
- [ ] panel roles displayed
- [ ] chart-type grammar displayed
- [ ] claim IDs displayed
- [ ] relative density visible

## Baseline comparison
- [ ] accepted baseline identified
- [ ] architecture score compared
- [ ] visual score compared
- [ ] anchor visibility compared
- [ ] panel balance compared
- [ ] whitespace compared
- [ ] global visual character compared

## Decision
- [ ] hard gates PASS
- [ ] blocking visual issues = 0 for PROMOTE
- [ ] manual final-size review completed
- [ ] PROMOTE / REPAIR / ROLLBACK / HOLD recorded
- [ ] reason recorded

## Repair
- [ ] smallest local defect identified
- [ ] protected baseline elements listed
- [ ] local repair applied
- [ ] full QA rerun
- [ ] baseline comparison repeated

## Final rendering
- [ ] architecture promoted before real-data rendering
- [ ] real source data used
- [ ] scientific sentinels checked
- [ ] final figure promoted separately
