# Example — biomedical four-figure architecture

## Figure 1 — design + primary contrast
- A: compact study design / provenance
- B: cohort/sample provenance
- C: primary effect or molecular contrast
- D: position in empirical/null distribution

## Figure 2 — robustness
- A: source-compatible sensitivity
- B: perturbation envelope
- C: leave-one-participant influence
- D: diagnosis-blind technical covariate

## Figure 3 — donor-level molecular evidence
- A: fixed-candidate heatmap
- B: focal candidate donor-level distribution
- C: model concordance
- D: perturbation robustness

## Figure 4 — external context
- A: compact routing schematic
- B: cross-dataset evidence matrix
- C: paired-state or related-condition context

This is an architecture example, not a template to apply mechanically.
