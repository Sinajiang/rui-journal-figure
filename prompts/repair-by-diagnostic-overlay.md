# Prompt — repair by diagnostic overlay

Use the diagnostic overlay and QA reports to identify the smallest real defect.

Do not redesign the figure unless the evidence architecture itself is defective.

For each issue:
1. cite the rendered object involved;
2. classify as BLOCKING or REVIEW;
3. identify the minimum local repair;
4. preserve scientific values and accepted visual hierarchy;
5. regenerate the final PDF/TIFF;
6. compare against the accepted baseline;
7. reject the repair if global visual quality worsens.

Never claim that automated geometry alone proves visual correctness.
