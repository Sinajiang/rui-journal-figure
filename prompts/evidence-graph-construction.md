# Prompt — evidence graph construction

Read the actual:
- Methods;
- Results;
- figure legends;
- promoted figures;
- source-data tables;
- supplementary list.

Do not fill gaps from general knowledge.

Construct a claim → figure → panel → source → statistic → legend → citation evidence graph.

For each manuscript claim:
- preserve the wording;
- classify strength;
- classify evidence status;
- link only to panels that actually support it.

Flag rather than repair:
- unsupported claims;
- contextual evidence presented as direct replication;
- mechanistic language without mechanistic evidence;
- panel citations inconsistent with the promoted artwork.

Then run the structural audit scripts.
