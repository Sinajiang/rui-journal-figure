# Prompt — journal-aware figure production

Before drawing:

1. identify the target journal and submission stage;
2. use the current official author guidelines;
3. generate or load the journal profile;
4. distinguish hard requirements from recommendations;
5. explicitly mark unspecified requirements as unknown rather than inventing them.

Then:
- build figure contract;
- build evidence architecture;
- choose chart types;
- generate baseline;
- run rendered-object QA;
- validate against the journal contract;
- perform final-size visual review.

If benchmark papers are used, extract transferable design grammar only. Do not copy exact layouts or copyrighted artwork.
