# Prompt — surgical repair

The current figure has an accepted scientific and visual baseline.

Do not redesign the whole figure.

1. Identify the exact collision / overflow / density defect.
2. Localize the minimum object that must change.
3. Preserve all accepted panel architecture, data, color semantics, and statistical values.
4. Repair by moving or resizing the local object before reducing font size.
5. Re-render the final PDF and TIFF.
6. Re-run collision, font-size, and visual QA.
7. Compare repaired version against the baseline and reject the repair if overall visual quality worsens.
