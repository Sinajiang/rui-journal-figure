# Prompt — automatic visual hierarchy and typography

Use the promoted architecture, v2.2 contribution weights, v2.3 layout grammar, and final physical figure dimensions.

Derive a bounded visual hierarchy:
- uniform font family and panel-label convention;
- narrow axis/tick/annotation size range;
- contribution-aware marker/line emphasis;
- physical annotation/tick/legend budgets;
- direct-label/shared-legend recommendation.

Never shrink text below the operational/journal floor to rescue an overpacked layout.
When a budget fails, prefer structural repair over font reduction.
