# Prompt — domain-adaptive figure planning

Before architecture optimization:

1. inspect Methods;
2. inspect Results;
3. inspect source tables;
4. infer candidate scientific domains;
5. choose one primary domain and optional secondary domains;
6. resolve the domain grammar;
7. use domain grammar to refine benchmark search and candidate figure planning.

Do not force the domain profile onto the manuscript.

For every domain-recommended figure archetype:
- map it to actually available evidence;
- classify as DIRECTLY_AVAILABLE / STRUCTURALLY_ADAPTABLE / OPTIONAL_NEW_ANALYSIS / NOT_APPLICABLE.

Use domain-specific risk flags during hostile review.

Examples:
- transcriptomics: do not promote a volcano plot when only a fixed candidate set exists;
- single-cell: do not treat cells as independent participants;
- prediction: do not stop at ROC without calibration;
- meta-analysis: do not force funnel plots with too few studies;
- multimodal: do not let the modality with the most variables dominate the narrative.
