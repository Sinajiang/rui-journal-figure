# Prompt — benchmark-informed automatic figure planning

You are planning the manuscript's main figures.

Your plan must be based on **both**:

## Internal evidence
Read:
- Methods
- Results
- current figure legends
- source tables / source data
- frozen analysis authority
- existing figures if present

Create an internal evidence inventory first.

## External benchmark evidence
Search for recent, high-quality benchmark papers.

Prefer:
1. target journal + similar question + similar data;
2. target journal + similar article type;
3. high-impact peer journal + similar design/data;
4. field-defining paper when necessary.

For every benchmark:
- explain why it is relevant;
- extract scientific figure architecture;
- extract visual grammar;
- distinguish transferable principles from study-specific features.

Do not copy exact artwork.

## Benchmark-to-study mapping
For every useful benchmark pattern classify:

- DIRECTLY_AVAILABLE
- STRUCTURALLY_ADAPTABLE
- OPTIONAL_NEW_ANALYSIS
- NOT_APPLICABLE

Never place OPTIONAL_NEW_ANALYSIS in the promoted figure plan unless the analysis has actually been completed.

## Generate candidate architectures
Produce 2–4 candidates when materially different valid architectures exist.

For each:
- figure-level claim;
- panel roles;
- chart types;
- source IDs;
- benchmark pattern IDs;
- main vs Supplementary allocation;
- unavailable evidence;
- optional upgrades.

## Score candidates
Score:
- scientific fidelity;
- claim coverage;
- contribution visibility;
- evidence diversity;
- benchmark concordance;
- journal fit;
- information efficiency;
- visual feasibility;
- evidence-boundary integrity;
- source traceability.

Recommend one plan.

## Critical rule
Benchmark papers should improve the plan, but the current study's Methods + Results + source data define what is actually permissible.
