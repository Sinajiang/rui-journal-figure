# Prompt — hostile visual review

Review this figure as a skeptical high-impact-journal editor.

Actively look for:
- unreadable text;
- panel imbalance;
- decorative content;
- information redundancy;
- hidden uncertainty;
- misleading axes;
- legend overload;
- collisions;
- panel labels that drift;
- visual emphasis inconsistent with scientific importance;
- tables disguised as figures;
- sparse panels that should be merged.

Return:
- blocking defects;
- non-blocking improvements;
- whether the figure should be promoted, repaired, or rolled back.
