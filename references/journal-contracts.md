# Journal contracts

Always check the current official author guidelines for the target journal.

Record:

- single-column and double-column width;
- maximum figure count;
- file formats;
- resolution;
- color mode;
- embedded-font requirements;
- whether legends are separate from artwork;
- whether figure titles belong in the manuscript rather than the image;
- source-data requirements;
- maximum legend length;
- AI-image policy if relevant.

Never assume Nature-family specifications automatically apply to another journal.

The skill should treat journal requirements as a versioned external contract.
