# Evidence architecture

## Figure-level question first

Before designing panels, write one sentence:

> What scientific question does this figure answer?

A strong figure generally contains a small evidence chain:

- **Anchor**: the primary result.
- **Support**: an orthogonal or donor-level view.
- **Robustness**: sensitivity or alternate model.
- **Context / boundary**: external dataset, mechanism, or limitation.

## Bad architecture

Avoid:

- four panels that all show the same effect;
- an oversized workflow beside tiny quantitative results;
- excessive schematic content when the study's contribution is empirical;
- a final panel that merely restates the legend;
- tables disguised as figures.

## Main figure vs Supplementary

Keep in the main figure only content necessary for the claim.

Move to Supplementary when a panel is:

- primarily diagnostic;
- a secondary parameter sweep;
- an exhaustive threshold grid;
- a long table;
- repetitive validation with no new inference.

## Claim escalation across figures

A manuscript often works best when figures escalate:

- Figure 1: design + primary contrast;
- Figure 2: robustness / sensitivity;
- Figure 3: donor-level or molecular detail;
- Figure 4: external context / mechanistic boundary.

The exact sequence depends on the paper, but the escalation should be explicit.
