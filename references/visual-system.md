# Visual system

## Typography

- Use one sans-serif family across the manuscript figures.
- Panel labels should be larger than axis text.
- Minimum final PDF text should normally be >=5.5 pt; target 6–8 pt for most axis/legend text.
- Avoid dense all-caps text.
- Avoid long prose inside figures.

## Color

- Assign colors by meaning, not panel.
- Keep group colors constant across the manuscript.
- Prefer 2–5 functional colors.
- Use gray for context, reference, non-significant or neutral elements.
- Check grayscale and color-vision accessibility.

## Lines and markers

- Use line width sufficient at print size.
- Keep marker shapes semantically stable.
- Use open vs filled markers only when that coding is explained clearly.
- Never place a significance star so close that it visually touches a point or axis.

## White space

White space is structural, not decorative.

Use it to separate:

- title from data;
- legend from data;
- neighboring panels;
- annotations from axes.

But excessive white space can weaken information density. Resize or merge sparse panels.
