# Benchmark figure grammar

The goal of benchmarking is to learn **design grammar**, not copy artwork.

For each benchmark paper, extract:

- what question the figure answers;
- which panel carries the anchor result;
- how supporting evidence is sequenced;
- how legends are minimized;
- how uncertainty and raw data are shown;
- how much schematic content is used;
- how much white space is tolerated;
- how visual emphasis tracks scientific importance;
- annotation-statistic placement: effect size, numeric CI, raw P, adjusted P/FDR/q, n, direction labels;
- whether statistical details are direct, legend-only, graphically encoded, or absent;
- significance style and legend statistical density.

Do not copy:

- exact layout;
- exact icons;
- exact colour arrangement when it is not semantically required;
- copyrighted graphical assets.

The output should be a short list of transferable principles that can be adapted to the current manuscript's actual data structure.
